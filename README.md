# Course Navigator

Obsidian 课程材料导航插件。把课件、实验、笔记、作业、视频、图片、网页、代码等各类文件组织进课程结构，随时知道每门课学到了哪里。

定位是导航：识别并组织材料，自己不做任何预览与转换。打开走统一协议——Obsidian 里注册了对应视图就直接打开（原生 PDF/图片/音视频，Office Reader、HTML Reader、Media Extended、Jupyter reader 等外部插件注册的扩展名会自动接上），代码文件交给外部编辑器（VS Code），其余交给系统默认应用。

## 功能

- **本组面板**：当前材料所在组的课件、实验、笔记、作业、视频一览，点击跳转
- **学习进度**：每门课一条游标——看到哪个文件第几页，标记一下，面板里一键跳回；本组面板里游标文件带页码徽标
- **作业记录**：每份作业一篇 md，关联材料、学习笔记与交付文件
- **手写件归档**：监听分享落地目录，按路由表把平板手写件自动归档进对应作业目录
- **材料识别**：pdf、docx、pptx、图片、html、epub、视频、音频、md、py/c/c++/ipynb 等各类文件都按目录与属性识别为材料，在菜单与面板里给出对应动作

## 安装

把仓库内容放进 `.obsidian/plugins/course-navigator/`（或直接 git clone），重启 Obsidian 后启用。

## 说明

- 纯 CommonJS 单文件插件，无构建步骤
- 运行数据存 `data.json`，不进仓库
- 目录约定：`<科目>/材料/` 下的文件视为材料，实验判定规则可在设置里配
